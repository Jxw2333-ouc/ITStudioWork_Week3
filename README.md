## 设计解释
- 主键为什么存在：PRIMARY KEYid区分不同的作者名，给每个数据绝对的编号防止重名
- 外键引用哪张表的哪一列：FOREIGN KEY 使用books表的author_id列
根据CONSTRAINT fk_books_author FOREIGN KEY (author_id)
- 价格为什么选择这个类型：DECIMAL不丢失精度小数，共8位，2位小数，非空默认0.00
DECIMAL(8,2) NOT NULL DEFAULT 0.00,
